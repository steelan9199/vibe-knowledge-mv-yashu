# 参考片拆解（只学味道，不抄画面）

三支片子是**风格坐标**：它们定义了「这一路视频长什么样」，不是素材库。任何一镜的构图、角色、歌词、配色比例都不许直接搬。新题材进来，画面必须从题材重新长出来。

---

## 片 A｜日不落（Claude 制作，仿 macOS 桌面叙事）

| 项 | 实测 |
|---|---|
| 规格 | 1920×1080 / 30fps / 45.833s / 1375 帧 |
| 来源 | 抖音二次压缩版，Lavf58.76.100，1.29 Mbps |
| 重复帧 | mpdecimate 1375 → 1375，**零重复** |
| BPM | 128.01 |

**结构**：假 macOS 桌面 + 假 Claude Code 终端 + 满屏像素插画，三层叠加。

**为什么它能判出是代码渲染**：画面里的数字自洽——时钟 03:00 走到 05:11、终端显示 `8693s`、气泡写「已离开 2:24:23」、天气 12°→18°。这些数只能从时间轴 `t` 推导出来，手填不可能这么准。

**可学的**：
- 数字/状态由 `t` 派生，而不是写死。
- 场景时长按小节取整（128BPM 下 4 小节 = 7.5s）。
- 用联系图目检节奏，不逐帧看图。

**不可学的**：这一路是「拟物叙事」，不是剪纸，本技能不复刻。

## 片 B｜DeepSeek 对照版（同一分镜，两个模型各画一遍）

| 项 | 实测 |
|---|---|
| 规格 | 1080×1920 / 30fps / 724 帧 / 24.13s（竖屏） |
| 结构 | 两条 1080×604（16:9）面板上下堆叠 + 黑边 + 居中标签 |
| 切点 | 3.63 / 5.77 / 7.47 / 10.43 / 13.87 / 17.27 / 20.23 / 22.37 |
| 关键发现 | 上下两版**切点逐帧重合**（7 个里 6 个完全一致） |

**结论**：同一份分镜 + 同一份逐字歌词轴，只有美术层不同。骨架外部给定，模型只负责「把这一秒画好看」。

**可学的**：
- **对比实验的做法**：先定骨架（分镜+歌词轴），再换美术，才有可比性。
- 骨架里最花脑子的部分（镜头调度、歌词触发）应当独立于美术层。
- 差距在材质密度：人物数量、波形分层、云的处理、颗粒粗细——都是「多画一层」的事。

## 片 C｜层叠剪纸 MV（本技能的直接对标）

| 项 | 实测 |
|---|---|
| 规格 | 1920×1080 / 30fps / 725 帧 / 24.17s |
| 切点 | 5.77 / 7.47 / 10.43 / 13.87 / 17.27 / 20.23 / 22.37 |
| 与分镜表 | 逐条对上（3.6/5.7/7.4/10.4/13.8/17.3/20.2/22.4） |
| 技术栈 | Remotion（React + SVG），提示词明写 |

**9 镜**：月亮海面 → 小船孤夜 → 念想泡泡特写 → 巨浪+纸鲸 → 黄昏码头 → 幕布撕开 → 孔明灯 → 眼睛 → 双人上船。

**三个真正值钱的设计**：

1. **纸片字幕**：每个字一张米色小纸片，各自微旋，当前字变橙红。全片统一度最高的一处，本技能已实现（`buildLyric`）。
2. **幕布撕开**（`leave`）：左右两半是两张纸，中间撕裂边，左边黄昏码头、右边夜海小船，两人越隔越远。全片创意高点。
3. **首尾闭环**：从月亮下的孤船开始，到最后两人同船、头顶还是那个月亮。

**它的失手处（要避开）**：`eyes` 那镜没做完——所谓「月亮化成眼里的倒影、里面是两个人」，实现成了一个通用眼球（径向纹理+高光点），主角没进眼睛，最后靠硬切到下一镜收场。**做嵌套缩放层，让内层是真的缩小场景，不要切镜。**

## 三支片子共同的味道（这才是要复刻的）

| 维度 | 共同点 |
|---|---|
| 美术 | 扁平矢量、纸层堆叠、留白大、边缘硬（不是柔和渐变） |
| 质感 | 纸张颗粒 + 纤维 + 暗角，颗粒是「胶片级」而非「噪点级」 |
| 色彩 | 低饱和、偏黄、一个强调色（橙红或金） |
| 字幕 | 手写/楷体，宽字距，落在画面下 1/10 处 |
| 节奏 | 切点严格落在拍上，镜头时长 = 整数小节 |
| 情绪 | 克制，不炫技，靠留白和光而不是靠特效 |

**一句话**：纸做的世界，光从后面打过来。
