# 字体与授权

## 只用这三款

| 文件 | 字体 | 字重 | 授权 | 用途 |
|---|---|---|---|---|
| `assets/fonts/kai500.ttf` | 霞鹜文楷 LXGW WenKai | Medium 500 | SIL OFL 1.1 | 字幕、标题、诗句（主字体） |
| `assets/fonts/hei300.otf` | 思源黑体 Noto Sans SC | Light 300 | SIL OFL 1.1 | 副标题、说明文字、小字 |
| `assets/fonts/hei500.otf` | 思源黑体 Noto Sans SC | Medium 500 | SIL OFL 1.1 | 强调字、数字、标签 |

CSS 里的名字固定为 `'Kai'` 和 `'Hei'`（`Hei` 靠 `font-weight` 区分 300/500），引擎已经写好 `@font-face`，不要改。

## 为什么是这三款

- **SIL Open Font License 1.1**：允许商用、允许嵌入、允许修改、允许再分发。唯一约束是**不能单独售卖字体文件本身**，以及修改后不能沿用原保留名（Reserved Font Name）。
- 霞鹜文楷：楷体骨架 + 手写感，正好匹配剪纸的“手工”气质。苹方/思源宋体都太“屏幕”。
- 思源黑体：中文黑体里字重最全、字面最规整的一款，做小字和数字不会糊。

## 绝对不要引入的

| 字体 | 问题 |
|---|---|
| 苹方 PingFang SC | 苹果系统字体，未授权商用分发 |
| 微软雅黑 | 微软/方正共有版权，商用需授权 |
| 思源宋体 Source Han Serif | 虽是 OFL，但本机未安装、未随技能分发；临时装了会破坏可复现性 |
| 汉仪 / 方正 / 造字工房任意款 | 商用必付费，抖音投流会被追 |
| 站酷系列 | 免费商用但字形风格不匹配剪纸（偏几何） |

**判断准则**：只要字体文件不在 `assets/fonts/` 里，就是违规。别用 `font-family: sans-serif` 兜底——不同机器会回退到不同字体，成片不可复现。

## 分发注意

字体文件随技能目录一起存放，属于 OFL 允许的“随软件分发”。若要把技能打包给别人，必须一并带上 OFL 授权文本（`assets/fonts/OFL.txt`，若缺失需从上游补）。

## 校验方法

出片后抽一帧放大字幕，检查：

1. 字形是不是楷体（有手写笔锋），不是黑体或宋体；
2. 有没有出现「□」或豆腐块（说明字体没加载，回退失败）；
3. 数字 `0` 是圆弧还是椭圆——霞鹜文楷的 0 偏椭圆，思源的 0 偏圆。

若字体没生效，检查 `build.mjs` 是否把 `<base href="./">` 换成了 assets 的绝对 `file://` 路径。HTML 输出到 `out/` 后，相对路径会指向 `out/fonts/`，那里没有字体，浏览器会静默回退——**这是最隐蔽的一类事故，画面看着正常，字体全错**。
