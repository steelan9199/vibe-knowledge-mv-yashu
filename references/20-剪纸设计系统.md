# 剪纸设计系统

这套美术是**代码画的**，不用 AI 生图。原因很简单：AI 生图做不到三件事——跨帧稳定（同一座山每小时都长得不一样）、精确时序（浪要在第 7 拍升起）、可复现（改一个字要重画全部）。

> **本文只描述「深蓝夜海 · 层叠剪纸」这一种风格。** 色板、九镜结构、海面基线的固定值在 `SKILL.md` §2 规格书里；本文讲的是"为什么这么画"。要换风格请派生新技能（`SKILL.md` §8），不要在这里写第二套参数。

> 本文参数与 `papercut.html` 1.1.0 对齐。**改了引擎签名/默认值，必须回来改这里**（见 `SKILL.md` §9.3）。

## 一、一张纸的四层

一张纸要看起来像纸，至少有「投影 + 本体」两层；要有体积和纸厚，再加两层：

```
┌─ ① 接触影  同形状 path，向下偏移 + 竖直渐变（不是实色）
├─ ② 错版白边 同形状 path，往左上偏 4~5px，米白，opacity .10~.19（可选）
├─ ③ 本体    fill: 该层颜色
└─ ④ 亮膜/受光 stroke + 竖直渐变（沿轮廓衰减，可选）
```

引擎实现是 `paperLayer(parent, opt)`（`papercut.html`）。四条实测结论：

**① 投影不能用「同形状整体下移的实心拷贝」。** 那样每层都得到一条硬边深色轮廓，配上沿那条亮线，一层纸就是一根上下双色的**灯管**；四层叠起来是一排灯管。真实投影是「贴边最暗，往下三十像素就没了」——所以用**同一形状 + 竖直渐变**，形状不动、亮度自己衰减：

```js
y1 = o.y - A0*.10,  y2 = o.y + max(18, o.shadow*2.6)   // userSpaceOnUse
```

**② 亮膜只能贴在浪脊上，且必须是渐变描边。** 整条轮廓用同一个亮度 `stroke` 一遍，四层就是四五条平行亮线，整片海读成**电线／心电图／栅栏**。改成沿高度衰减的渐变之后，边缘是「受光」，不是「被画出来」。

**③ 渐变必须 `gradientUnits="userSpaceOnUse"`，按振幅定位。** 用百分比（默认 `objectBoundingBox`）时，路径一直延伸到画面底部，写成 26% 的窄亮带会变成 100px 宽的一大片暖膜。

**④ 不要用 `filter: drop-shadow`。** 逐帧渲染成本高，且部分 Edge 版本合成层会抖动；同形状路径偏移成本接近零。

| `paperLayer` 关键参数 | 含义 | 常用值 |
|---|---|---|
| `y` / `amp` | 基线高度 / 振幅刻度（**×6 成像素**） | 场景自定 / 6~12 |
| `cap` | 单层浪高上限（**软顶**） | 层距 × .74~.85 |
| `teeth` | 扇贝道数 | 见 §三 |
| `shadow` | 接触影厚度 | 10~40 |
| `rim` | 亮膜宽度，`0` 关闭 | 1.4~3 |
| `face` | 受光面色，`null` 关闭 | `P.glow` |
| `misreg` / `misregO` | 错版白边色 / 不透明度 | `#f7efdd` / .10~.19 |


## 二、撕纸边

剪纸的边不是直的，是「被撕开」的。算法：沿边每隔 ~90px 取一个齿点，齿点 y 值加确定性抖动，用二次贝塞尔连接，控制点向随机方向偏 0.35–0.65 个齿距。

```
tornPath(w, h, y, amp, seed, teeth)
```

- `amp` = 振幅，一般 12–18px。超过 24px 像锯子，低于 8px 看不出来。
- `seed` 固定 → 形状固定。**换 seed 就是换一张纸，这是个免费的多样性来源**：同一条浪，seed 不同就是不同手撕的纸。
- 竖直撕边（幕布中间那道）用 `tornEdge()`，齿更密（每 26px 一个）。

## 三、扇贝浪（海面的唯一原语）

纸浪的经典轮廓是**一排向上的圆弧（scallop）**，不是正弦波。正弦波是「水面」，扇贝是「纸」。

```js
scallopPath(w, h, y, amp, seed, count, cap)
//   画布宽 画布高 基线 振幅刻度 随机种子 道数 浪高上限（软顶，可省）
```

**弧宽、弧高、密度，三样都写死在这一个函数里，不要在外面另起一套。** 五条实测约束：

1. **`amp` 是刻度，不是像素。** 函数内 `A0 = clamp(amp*6, 20, 190)`。传 9 ≈ 54px 上限。早先按 ×3.6 换算过，叠上重尾分布后绝大多数浪只有 8px 高，一层海就是一马平川——纸的浪必须在**层距量级**上起伏，层与层才咬得住。
2. **道数由画幅推：约 `W/(100+i×34)` 道**（`i` 是层序，远=0）。1920 宽下依次 19/16/13/11 道。**远的碎、近的整**——这是「远小近大」在浪上的唯一体现。
   - 反向（近处更密）是把高频锯齿放在前景，配上每层的描边，整片海读成心电图。
   - **弧宽是硬约束**：一屏少于 7 道（弧宽 > 275px）时，**无论多圆都是一个土丘**。加密比调振幅有效。
3. **段宽下限 0.78**（`ws` 的抖动范围 `.78 + pow(r,1.2)*1.75`）。段宽只有波长一半时，峰到谷的水平距离比浪高还短，**几何上装不下一个圆**——必然尖。
4. **浪尖偏后**：峰点落在段宽的 `.58~.74` 处，前坡长、后坡短，水才有方向。但不要超过 `.75`：后坡只占 1/4 段宽时，那一侧就是**悬崖**，剪影立刻读成山脊。
5. **`cap` 必须是软顶，不是硬截。**

```js
const raw = A0 * (.10 + swell(i) * 1.28);
const a = cap ? cap * Math.tanh(raw / cap) : raw;   // ✓
const a = Math.min(raw, cap);                        // ✗ 削成平台
```

`Math.min` 把所有超过上限的涌群压成同一高度，浪顶齐平、两端各留一个折角，读起来是土坡。

### 层叠公理（有 `cap` 的地方都适用）

**互相叠压的纸层，每层浪高 ≤ 层距 × 0.74~0.85。**

- 低于 0.74：浪缩在层带里，看起来是「四条色带」而不是海。
- 高于 0.85：近层浪尖翻到远层基线之上，层不再套着层，海变成「平原前面立着几座山」。
- **手写层（不走 `seaStack`）最容易漏 `cap`**：写 `amp: 36` 就等于允许 190px 浪高，而层距只有 58px——实测画面就是三四倍层距高的蓝墙，放大后能看到峰顶到谷底的水平距离只有落差的 1/3，那就是一道悬崖。**凡手写多层，逐层写死 `cap`。**

### 平滑：峰和谷的切线必须水平

采样点列（谷→峰→谷）交给 `smoothD(P, noLead)` 用 Catmull-Rom 统一过一遍，**不要逐段各拼一条贝塞尔**——段接头处切线不连续，一排浪就是锯齿山。

`smoothD` 里有一处关键判断：某点若是 y 方向的局部极值（峰/谷），则把切线压平 `my = 0`。标准 Catmull-Rom 取 `(p2-p0)/6`，浪尖前后两点一高一低时这个切线是斜的，**曲线在最高点被拉出一个折角**。这不是振幅问题，是把峰当成了拐点。


## 四、颗粒与纤维

三层 CSS overlay，一次性栅格化，逐帧零成本：

| 层 | 做法 | 混合模式 | 不透明度 |
|---|---|---|---|
| `#grain` | `feTurbulence fractalNoise baseFrequency .86` 转灰度，做成 260px 平铺 | `overlay` | .40 |
| `#fiber` | `feTurbulence turbulence baseFrequency "0.004 0.09"`（横向拉长） | `soft-light` | .16 |
| `#vignette` | 径向渐变，42% 处透明 → 100% 处 rgba(0,0,0,.42) | — | — |

## 五、色板

引擎内置七套（`PAL`），全部低饱和、偏黄——因为它们是「纸的颜色」，不是「屏幕的颜色」。**这七套是给一条片子写的，不是通用色卡**：键名就是那条片子的情绪线（冷夜→压暗→蓝紫过渡→暮色玫瑰→灯火→深紫→回到冷夜）。换题材时**照结构重写**，别硬套。

```js
PAL.xxx = { sky: [上, 下], moon, sea: [远…近 4 档], ink, glow, warm }
```

| 键 | 用途 | 天 | 海（远→近） | 强调 |
|---|---|---|---|---|
| `night` | ① 启航：冷夜，天最亮 | `#1a2e46→#0a141f` | 蓝，逐层压深 | `warm #e8b878` |
| `deep` | ② 孤夜：压到最暗 | `#101f31→#060d16` | 墨蓝 | `warm #c99a63` |
| `dusk1` | ③④ 蓝紫过渡：冷色开始破 | `#2b2e4c→#141828` | 蓝紫 | `warm #e0a877` |
| `dusk2` | ⑤⑥ 暮色玫瑰：全片最暖 | `#8c5b67→#482c3b` | 玫瑰红 | `warm #ffc48a` |
| `ember` | ⑦ 灯火：暖褐 | `#3a2430→#1a1018` | 暖褐 | `warm #ffbe72` |
| `mauve` | ⑧ 你眼中：深紫 | `#241b2e→#0e0a14` | 深紫 | `warm #e8b878` |
| `back` | ⑨ 尾声：回到冷夜 | `#16283c→#0c1622` | 冷蓝 | `warm #e8b878` |

三条实测：

- **每镜只能有一个强调色**（金或橙红）。两个以上强调色 = 廉价。
- **`sea` 必须是 4 档且逐档压深**，因为 `seaStack` 直接用 `i0+k` 索引它，层数超过 4 时按「远色→末档→`ink`」重新取样。只给 2 档，第 3 层就会和 `ink` 撞成一块死黑。
- **相邻两镜的 `sky[0]` 亮度差要小。** 实测把 `dusk2.sky[0]` 从 `#b9757e` 压到 `#8c5b67` 之后，第 4→5 镜的「暖」是慢慢渗出来的；原来那一下像有人把灯一下开到底。

色板写在场景函数首行（`const P = PAL.dusk1`），改风格要改这一行 + `PAL` 表。

## 六、人物造型

小人不是「画得像」，是「比例对」。固定比例表（以 `kid()` 的 `s=1` 为单位）：

| 部位 | 尺寸 | 说明 |
|---|---|---|
| 头半径 | 22 | 全片不许变 |
| 眼距 | 15（±7.5） | 眼半径 2.1，纯黑点 |
| 头身比 | 1 : 2.1 | 头 22，身 46 |
| 身体 | 梯形 `M-26,0 Q-26,-46 0,-46 Q26,-46 26,0 Z` | 下摆宽 52 |
| 发 | 覆盖头顶 2/3，带一撮翘起 | 剪影感，不画五官细节 |

**跨镜头一致性靠这张表，不靠“记得画一样”**。9 个镜头里同一个人长成两个人，是这类片子最常见的翻车点。

## 八、不要做的事

- **不要用 AI 生图做背景**。跨帧不一致 + 无法精确时序，必翻车。
- **不要用渐变做天空主体**。天空可以渐变，但必须有 2–3 层纸云压在上面，否则像 PPT。
- **不要给纸加内发光**。剪纸是实体，光是「从后面透过来」和「上沿被照亮」，不是自发光。
- **不要超过 6 层浪**。7 层以上颜色分不开，变成一坨。
- **不要用整层 `opacity` 做远近**。见 §十。
- **不要画「一道立起来的卷浪」**。见 §九。

## 九、单帧可读性（先过这关，再谈好不好看）

**核心事实：在静止帧里，一个「轮廓完整、体量高大、有明暗渐变的深色实心团块」，人眼只有两种解释——山，或者建筑（拱门／隧道口）。**

这条不是审美偏好，是识别机制。所以下面这些「补救」全部无效，别再试第二次：

| 你加的 | 你以为的效果 | 实际 |
|---|---|---|
| 浪脊上加白色泡沫条 | 「这是浪」 | 山脊上的雪／冰川裂缝 |
| 把前坡改陡、后坡改缓 | 「有翻卷感」 | 更像一道崖壁 |
| 把体量拉高 | 「巨浪」 | 更确定是山 |
| 加浪壁白口、加悬垂的浪舌 | 「卷起来了」 | 拱门／隧道口／帐篷 |

一条片子的实测记录：同一镜连试七轮单片卷浪（单轮廓 → 加泡沫 → 改曲率 → 弧带叠压 3 层 → 加厚 → 2 层带悬垂舌），单帧依次被判成「蓝色山脉」「带缺口的山」「三道拱门」「两顶帐篷」。**换画法没救，只能换语言。**

### 浪要显「巨」，只有三条合法路径

1. **层数多**：4~6 层互相叠压的扇贝浪，层层咬住，海面本身有纵深。
2. **参照物小**：船、人、灯。观众靠「船只有浪的 1/20 高」推出浪有多大——**这是唯一能真正说服人的尺度证据**，比把浪画高有效一个数量级。
3. **前景压边**：贴着画面底边的一道近浪，只露浪尖。它把「镜头很低、就在水面上」说清楚，同时把画面下缘封住。

三条都做到，浪不需要立起来也「巨」。

### 判据（出图先过这三问）

1. **缩到 320px 宽再看一眼**：还能认出是海吗？认不出就是形状问题，不是细节问题。
2. **眯眼**：只剩剪影时，画面里有没有「一个完整的大团块」？有 → 会被读成山/建筑。
3. **1:1 放大边缘**：峰顶到谷底的**水平距离**是否 ≥ 落差的 2 倍？不到 → 那是一道崖壁，不是浪。

## 十、纵深靠掺色，不靠透明

纸是不透明的。让远处的纸退后，用 **`mixHex(色, 天色, t)`** 往天色里掺：

```js
fill: mixHex(P.sea[0], P.sea[2], .50)     // ✓ 一块更浅的实心纸
fill: P.sea[0], opacity: .5               // ✗ 半透明塑料膜
```

半透明的纸在叠压处会透出下层轮廓，纸的实体感立刻消失；而且层与层的颜色差会被压成「同一块色上的深浅波动」，四层海糊成一片。

**唯一可以用 `opacity` 的是「光」不是「物」**：亮膜（.10~.30）、接触影（.28~.62）、错版白边（.10~.19）、倒影碎光。这些本来就是半透的；纸本体必须实心。
