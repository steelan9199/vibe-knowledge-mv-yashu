`BUILDERS`（1825–1828）是 type → 函数的注册表；**新增 `scXxx` 必须在这里注册**，否则 story 里写的新 type 会静默回落到 `scSail`（1919 行附近有兜底）。

**同一原语可以出现多次**（长片拆镜）。区分靠 `scenes[]` 里的 `zoom`/`flip`/`panX`/`panY`，由 `applyVariant()` 在装配层套一层外层 transform（1929）。**不要往 `scXxx()` 里加推拉参数**——9 个函数各一套语义，改不动也维护不了。

## 6. 调试入口（省 token 的关键）

| 参数 | 作用 | 用法 |
|---|---|---|
| `?t=0.37` | 定格到**全片归一化**时刻 | `shot.mjs --t 0.37` |
| `?hide=grain,fiber` | 按 id 关层 | 顶部 CSS 层：`stage art vignette fiber grain lyric fade` |
| `?hide=.crowd` / `[data-paper]` | 按选择器关层（v2.0.1 新增） | 二分定位「这块是谁画的」 |

可用 class：`air boat bub cloud crowd curl dock esheet hero kid moon reflect sl stars whale`；
所有纸层（`paperLayer`）都带 `data-paper` 属性 —— `--hide '[data-paper]'` 一关就等于把海抽走。
**注意 `--hide scene` 是旧文档里的错写法，引擎里没有这个 id，什么都不会发生。**

## 7. 脚本速查

| 脚本 | 什么时候用 | 主要参数 |
|---|---|---|
| `beat.mjs` | 换歌才跑（同一首曲子跑一次就够） | `--audio --out --strong-every` |
| `beats-info.mjs` | 查已有的 beats.json：某秒最近是哪一拍 | `--at 12.3` `--snap 8.4` `--check` `--json` |
| `build.mjs` | 把 story.json 注入引擎，出单文件 HTML；**同时拦时长/镜数/变体/end 位置四类错** | `--story --out`，成功时打印分镜时间表与建议镜数 |
| `render.mjs` | 出片 | `--html --aspect wide --duration --workers --limit --bgm --format --quality` |
| `shot.mjs` | 单帧排查（**最常用**） | `--t --crop x,y,w,h --scale k --hide` |
| `sheet.mjs` | 九宫格看镜头间连贯（**只定位不定性**） | `--frames --cols --at` |
| `probe.mjs` | 改海参数前先看几何 | `--layers '<json>'` / `--gap --amp --cap --teeth --seed` |
| `tok.mjs` | 一条片子做完记账 | 无参 = 最近会话；`--compare a b` |

> `assets/` 里目前**没有** `beats.json`（`beats-info.mjs` 头注释说"自带"，是旧说法）。
> 第一次做片子要自己 `beat.mjs --audio … --out assets/beats.json`，之后复用。

每个脚本都支持 `--help`，**想知道参数就打 `--help`，不要读脚本源码**。
