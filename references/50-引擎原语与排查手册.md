# 引擎原语与排查手册

给**要动手改 `assets/papercut.html` 的人**看。只关心「怎么调参数出片」的，看 `SKILL.md` 就够。

铁则：**本文件的签名必须与代码逐字一致。** 文档写了一个不存在的参数，比没有文档更坏——下一个人会照着它写，然后以为是引擎坏了。

> **分层原则：§二 的原语（`scallopPath` / `tornPath` / `paperLayer` / `smoothD` / `mixHex` …）是跨风格通用的几何层，派生新风格时一行都不用改；§一 的文件职责与 §五 的症状表是**本风格**的，派生时要重写。**

## 一、文件职责

| 文件 | 职责 | 什么时候改 |
|---|---|---|
| `assets/papercut.html` | **引擎 + 全部美术**。单个 HTML，内含 9 个场景函数、图形母题库、渲染循环 | 改画法、加原语 |
| `assets/story.example.json` | 分镜与歌词轴样例 | 换片子的起点 |
| `scripts/build.mjs` | 把 story.json 注入 html 的 `/*__STORY__*/` 占位符 | 极少改 |
| `scripts/shot.mjs` | 单帧探针（Edge headless 截一张） | 排查美术 |
| `scripts/sheet.mjs` | 联系图（按分镜中点自动取九帧拼图） | 看镜头之间顺不顺 |
| `scripts/render.mjs` | 逐帧截图 → ffmpeg 合成 mp4 | 出片 |
| `scripts/beat.mjs` | BPM / 拍点实测 | 每片一次 |

`papercut.html` 里**没有构建期、没有依赖、没有 import**。所有函数都在同一个 `<script>` 作用域内，改完刷新即生效。

## 二、原语签名（1.1.0 实测）

### 纸与浪

```js
scallopPath(w, h, y, amp, seed, count, cap)   // → path d 字符串（不落 DOM）
tornPath(w, h, y, amp, seed, teeth)           // → path d 字符串
paperLayer(parent, opt)                       // → <g>，带 g.__d 可复用路径
seaStack(root, P, opt)                        // → [<g>, …]（4~6 层海，自己算 cap 与道数）
reflect(parent, x, y0, y1, w, col, seed)      // → <g>（月光碎光柱）
```

`paperLayer` 的默认值（**改默认值必须同步本表**）：

```js
{ w: W, h: H, y: H*.6, amp: 14, seed: 1,
  fill: '#12283c', shade: 'rgba(0,0,0,.42)', hi: 'rgba(255,255,255,.10)',
  teeth: null, shadow: 11, mode: 'sea', face: null, rim: 2.4,
  misreg: null, mdx: -4, mdy: -5, misregO: .5, cap: null }
```

| 参数 | 作用 | 关掉它 |
|---|---|---|
| `shadow` | 接触影厚度（px）。**渐变**而非实色拷贝 | `0` |
| `rim` | 亮膜宽度。**渐变描边**，沿高度衰减 | `0` |
| `face` | 受光面颜色 | `null` |
| `misreg` / `misregO` / `mdx` / `mdy` | 错版白边色 / 强度 / 偏移 | `null` |
| `cap` | 浪高软上限 | `null` = 不限 |
| `mode` | `'sea'` 扇贝 / `'torn'` 撕边 | — |

`seaStack` 的 `opt`：

```js
{ top: H*.56, gap: 62, amp: 12, seed: 300, white: '#f7efdd',
  count: 4, i0: 0, ampStep: 2.4, hiI: .16, hiStep: .05 }
```

它内部已经做了三件事，**自己手写多层时要么复用它、要么照抄这三件**：
`cap: gap*.74`、`seg = max(5, round(W/(100+i*34)))`、层数超出 `P.sea` 档数时按「远色→末档→ink」重取样。

### 图形母题

```js
sky(g, c1, c2)                          // 全屏天空渐变
airGlow(root, x, y, r, col, op)         // 月亮周围的大气光晕
moon(parent, x, y, r, col, opt)         // 纸月亮（错版白边 + 上亮下暗 + 下沿纸厚）
stars(parent, n, seed)                  // 星点
boat(parent, x, y, s, opt)              // 纸船；opt { hull, sail, ink }
kid(parent, x, y, s, opt)               // 小男孩；opt { body, skin, hair, lantern, glow }
whale(parent, x, y, s, col)             // 纸鲸（含尾鳍、胸鳍、喷水）
skyLantern(parent, x, y, s, seed)       // 孔明灯
cutBlob(cx, cy, rad, seed, pts, jag)    // 不规则闭合纸片（月海/洞/云团）
```

`boat` / `kid` / `whale` / `skyLantern` 的 `x, y` 是**锚点**（船底中线、脚下、鲸腹），不是包围盒左上角。

### 小工具

```js
mixHex(a, b, t)        // 两色按 t 混合（掺天色做纵深，不用 opacity）
rng(seed)              // → () => [0,1) 确定性随机。**禁用 Math.random**
tr(e, x, y, s, rot)    // 设置 transform：平移 + 缩放 + 旋转（deg，顺时针为正）
setOpacity(e, o)       // 改 opacity，自动 clamp
mk(tag, attrs, parent) // 建 SVG 元素
```

## 三、三个符号坑（都实际翻过车）

1. **SVG `rotate` 顺时针为正。** 船头朝右时，`lerp(4, -12, p)` 是**抬头**；写成 `lerp(-13, 7, p)` 就是让船头扎进水里。改旋转前先在纸上画一下正的角往哪转。
2. **y 轴向下。** 「浪高」= `y - a`；「越远」= y 更小。判断极值时 `b[1] <= a[1]` 是**峰**，不是谷。
3. **`gradientUnits` 默认是 `objectBoundingBox`。** 而纸的路径一直延伸到画面底部，包围盒几乎是全屏——按百分比定位的亮带会变成上百像素宽的一片。**凡按高度定位的渐变，一律 `userSpaceOnUse` + 绝对坐标。**

## 四、排查流程（不要整帧猜，按这个顺序）

```bash
cd ~/.workbuddy/skills/vibe-knowledge-mv-yashu

# 0. 先算抽帧时刻：--t 是全片归一化，不是镜内进度
#    t = (cumStart + dur/2) / duration

# 1. 单帧（~2s，比渲视频快一个数量级）
node scripts/shot.mjs --html out/story.html --t 0.37 --out out/a.png

# 2. 隔离图层：先确认是形状问题还是叠加问题
node scripts/shot.mjs --html out/story.html --t 0.37 --hide grain,fiber,lyric --out out/b.png
node scripts/shot.mjs --html out/story.html --t 0.37 --hide scene --out out/c.png

# 3. 1:1 放大（crop 取真实像素，整数倍 + neighbor 保硬边）
ffmpeg -y -i out/a.png -vf "crop=960:230:0:790,scale=1440:345:flags=neighbor" out/z.png

# 4. 联系图：镜头之间顺不顺
node scripts/sheet.mjs --html out/story.html --out out/sheet.png   # 默认关颗粒
```

**第 3 步不能省。** 实测两处整帧看不出的问题都只在放大后暴露：船头角度反了（帆往右倾、船头扎水）、浪峰成墙（峰顶到谷底水平距离只有落差的 1/3）。整帧缩到 640px 时这些都「看起来还行」。

### 改完代码必做的确认

`build.mjs` 只是把 JSON 注入模板，**它不会提示你语法错误**——场景函数报错时页面会静默停在第一帧。所以每次改完：

```bash
node scripts/build.mjs 2>&1 | tail -3          # 看 "输出 … (XX KB)" 有变化
grep -c "你刚改的那行特征字符串" out/story.html  # 确认改动进了产物
node scripts/shot.mjs --html out/story.html --t <该镜中点> --out out/verify.png
```

`grep` 计数为 0 = 改动没进产物（改错文件/被 build 覆盖），别急着调参数。

## 五、症状 → 查哪里

| 症状 | 先查 | 常见根因 |
|---|---|---|
| 同一镜头重渲两次不一样 | `seek()` 是否纯函数 | 用了 `Math.random()` / `Date.now()` / 上一帧状态 |
| 页面停在第一帧、后续全黑 | 场景函数抛异常 | 拼 SVG 字符串时引用了未定义变量（如渐变 id） |
| 海面读成山 | 该层 `cap` 与道数 | 手写层漏 `cap`；道数 < W/275，弧太宽 |
| 浪顶成尖三角 / 锯齿 | `smoothD` 的 `my = 0` + 段宽下限 | 逐段拼贝塞尔；段宽 < 波长一半 |
| 浪顶成平台 | `cap` 实现 | 用了 `Math.min`，应改 `cap*tanh(raw/cap)` |
| 整片海出现平行亮线 | `rim` | 亮膜写成纯色、不沿高度衰减 |
| 一层纸上下双色像灯管 | 接触影 | 用了下移的实心拷贝，应改同形状 + 竖直渐变 |
| 远处一层和 `ink` 糊死 | 色板 `sea` 档数 | `sea` 少于 4 档，`seaStack` 重取样后撞色 |
| 人物跨镜变脸 | `KID` 比例表 | 直接改了 `kid()` 里的数字而没走比例表 |
| 字幕超出画面 | 单句字数 | > 12 字；分词还受 `charSnap` 影响 |
| 渲出来有残帧/撕裂 | worker 数 | 超过物理核一半，合成线程抢 CPU |

## 六、性能（Windows / 1920×1080 / 本机实测）

| 动作 | 耗时 | 备注 |
|---|---|---|
| `build.mjs` | < 1s | 纯字符串替换 |
| `shot.mjs` 单帧 | 1.9~2.9s | 含启动 Edge + 载入 + 等字体 |
| 全片 24.1s / 30fps = 723 帧 | 见 `render.mjs --workers` | 默认每 worker 半物理核 |
| 输出格式 | `jpeg q95` 默认 | 1080p PNG 单帧 1.5~3MB，base64 过 CDP 是主要瓶颈 |

`--workers` 不是越大越快：超过物理核一半，合成线程互相抢 CPU，`settle` 时间内会截到**还没画完的帧**（表现为随机几帧残缺）。宁可少开。
