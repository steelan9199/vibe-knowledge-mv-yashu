# SVG 正角是低头，船头扎进水里

## 症状

第 4 镜小船向右划，1:1 放大（`out/_z_boat4.png`）发现：帆明显向右倾，**船头（右舷）却扎进水里**，整条船像在俯冲。整帧缩到 640px 宽时完全看不出来——只当是「船在浪里」。

## 根因

`tr(e, x, y, s, rot)` 里 `rot` 直接写进 SVG `rotate(deg)`，而 **SVG 的旋转正方向是顺时针**。船头在右，要让船头抬起来必须**逆时针**转，也就是负角。

原代码 `lerp(-13, 7, p)`：起点 -13（船头抬起）、终点 +7（船头下压）。船越划越快、头越低，正好反了。

## 修法

改 `lerp(4, -12, p2)`：起手微抬、行进中继续抬头，配合 `Math.sin(t*1.9)*2.2` 的浪涌摆动。

```js
const tilt = lerp(4, -12, p2) + Math.sin(t * 1.9) * 2.2;
tr(bo, bx, by, .95, tilt);
```

## 是否已改引擎

否（改的是 `scBrave()` 的运镜数值）。符号规则已写进 `references/50` §三「三个符号坑」第 1 条。

## 下次先做什么

写任何旋转前，先在纸上画一遍：**这个物体朝右时，正角会把它转到哪边。** 然后用 1:1 放大验证——这类错误整帧目检抓不到。
