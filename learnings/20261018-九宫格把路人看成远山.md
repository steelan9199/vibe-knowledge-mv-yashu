# 九宫格缩略图把 18 个路人看成了一座远山

## 症状

全片联系图（`out/sheet-a.png`，每帧缩到 400px 宽、4×3 拼贴）里，第 5 镜 `scDock` 画面右下出现：

1. 一条**锯齿状深色带**，横贯画面下三分之一，读起来像"一层远山"；
2. 画面右下角还有一道**巨大的弧形硬边**，像有个圆被裁掉了一角。

据此得出两条"结论"：第 5 镜缺第二层远山、`airGlow` 半径不够。差点去改这两个东西。

## 根因

**缩到 1/4 大小后，细节被平均成了大色块，人眼会自动补成"最熟悉的那个东西"。**

- "远山"：实际是 `scDock()` 里远排 **18 个人流剪影**，每个约 30~40px 宽、头部与肩部各有 2 个小起伏。单看每个都是人，连成一条 700px 的带子、缩到 1/4 后，起伏被压平、只剩一条带毛刺的深色轮廓 → 完美符合"山脊线"的特征。**`scDock()` 里根本没有远山对象。**
- "弧形硬边"：查 `airGlow()` 实现（行 1197 起），四个 stop 的**末档 opacity 就是 0**，本身就是软边，不存在硬边。抽 `out/dock.png` 1:1 看，画面干净。

同样的机制在第 4 镜也出现过一次：缩略图里"每道浪顶端有个尖齿"，1:1 放大后发现是浪尖偏后 + 扇贝太疏的合效果，不是"尖"。

## 修法

**任何"这里有块奇怪的东西"的判断，定性前必须抽 1:1 单帧。** 这是 `SKILL.md` §6 质检表里"1:1 目检"那一行的存在理由，本轮自己没遵守，白花两轮排查。

判据：**联系图只用来看构图、景别、明暗节奏、相邻镜是否可辨**；一旦要判断"这个形状对不对"，立刻：

```bash
node scripts/shot.mjs --html out/story.html --t <该镜中段> --out out/f.png
# 可疑区域裁出来放大 1.5~2 倍（neighbor 保硬边）
ffmpeg -y -i out/f.png -vf "crop=960:230:0:790,scale=1440:345:flags=neighbor" out/z.png
# 还分不清是形状还是叠加，就隔离图层
node scripts/shot.mjs --html out/story.html --t <t> --hide grain,fiber,lyric --out out/f2.png
```

顺带一条：**这条经验本身也是铁律 8 的复现**——"完整轮廓 + 连成一片 + 深色 = 山"。当时如果先套这条铁律，会立刻想到"这可能是人群不是山"，根本不用抽帧。
